# cloee-firmware

Public distribution channel for Cloee firmware (screen and scale): signed release manifests and firmware images only.
The source repositories are private. Every image is signed (ECDSA P-256 / SHA-256) and the devices verify the signature themselves before installing;
nothing in this repository is trusted without that signature. No credentials are, or ever will be, contained in any file here.

Contents are generated by the release workflows of the private repositories; do not edit by hand.
